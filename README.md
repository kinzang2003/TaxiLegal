# numkhor-legal

Privacy Policy, Terms & Conditions, and account deletion info for NumKhor. Static Next.js site, no backend/env vars needed — deploy as-is to Vercel.

Update the "Last updated" date in `src/app/privacy/page.tsx`, `src/app/terms/page.tsx`, and `src/app/delete-account/page.tsx` whenever their content actually changes.

## Develop

```
npm install
npm run dev
```

## Deploy

Push to GitHub, then import the repo in Vercel — no configuration needed, it's a standard Next.js app.
